Canvas accessibility check

A bookmark that flags heading, alt text, link, table and embed problems on Canvas pages, Modules and the Pages list. It always runs the latest version, so you only install it once.

A11y check

Drag the button to your bookmarks bar.

Install

  1. Show your bookmarks bar if it’s hidden: ⌘ Shift B on Mac, Ctrl Shift B on Windows. In Safari, choose View, then Show Favorites Bar.
  2. Drag the A11y check button onto the bar.
  3. Open a Canvas page, Modules or the Pages list and click the bookmark.

Using it

  1. On a single page, a panel lists every issue. Click one to jump to it.
  2. On Modules and the Pages list, each item gets a badge. Click a badge to see that item’s issues.
  3. In the editor, use Canvas’s built-in Accessibility Checker instead.

Not covered

Color contrast, video captions, reading order and attached files such as PDFs and slides. Check those by hand.

Use Tampermonkey? Install the userscript instead, and the check runs on its own every time you open a page.
