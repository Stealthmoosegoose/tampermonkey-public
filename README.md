# tampermonkey-public

Userscripts and bookmarklets for working in Canvas LMS.

| Script | What it does | Install |
| --- | --- | --- |
| [Canvas A11y Flagger](canvas-a11y-flagger/) | Flags heading, alt text, link, table and embed accessibility issues on pages, Modules and the Pages list | [Install page](https://stealthmoosegoose.github.io/tampermonkey-public/canvas-a11y-flagger/) |
| Highlight broken links | Highlights broken links on Canvas pages | [Install](https://raw.githubusercontent.com/Stealthmoosegoose/tampermonkey-public/main/public-canvas-highlight-broken-links.user.js) |
| Split view sync | Keeps navigation and scrolling in sync between two Canvas windows | [Install](https://raw.githubusercontent.com/Stealthmoosegoose/tampermonkey-public/main/public-canvas-split-view-sync-navigation%2Bscroll.user.js) |

Userscripts need the [Tampermonkey](https://www.tampermonkey.net/) browser extension. Opening an install link shows Tampermonkey's install screen.
